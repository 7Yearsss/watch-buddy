## 开发顺序

1. ✅ 搭项目（TypeScript monorepo：`packages/engine`、`apps/sim`，以后加 `apps/web`、`apps/server`）
2. ✅ 引擎：基线 → 回响 → 成长值 → 进度条和进化条件
3. ✅ 引擎：野怪遭遇 + 对战（种子固定、可回放）+ 周循环 + 周 Boss
4. ✅ 批量模拟（1,000 个假用户），对照数值目标调参，结果见 [SIMULATION.md](SIMULATION.md)
5. ✅ 手表尺寸的网页原型（功能清单见 [PROTOTYPE.md](PROTOTYPE.md)）
6. 按 07 打磨：✅ 早晨卡片 ✅ 小惊喜 ✅ 演出 ✅ 帧动画；另加好友切磋、手表分页、小组件和通知、作息、首次打开、辅助功能、分享图
7. 接 AI（宠物说话、周信）
8. 官网 v1（落地页、候补名单、隐私政策）+ 服务器 + 真正的好友系统，见 [10](design/10-技术架构.md)
