# 项目交接：Apple Watch 健康宠物对战游戏（规划阶段）

## 背景与灵感
- 起因：独立开发者 BaiFu 做的 Auday（把 Apple Watch 变成 AI 录音笔），买断 19.9 美元，国庆一周卖了约 30 万美元。
- 借鉴的模式：用户本来就戴着的设备 + 替代一个专用硬件 + 一句话讲清卖点 + 15 秒视频能让人"哇"出来。
- 产品方向：类宝可梦 / 数码宝贝电子机 / 拓麻歌子的手表宠物，核心卖点是"你越健康，你的宠物越强"。

## 核心玩法（已定）
- 宠物靠真实健康数据成长：步数、跑步、力量训练、睡眠、HRV 等换算成速度、攻击、防御、体力、恢复等属性。
- 属性按"跟自己过去比的变化"计算，不看绝对值。这样对普通人公平，也能抹平不同品牌手表的数据差异。
- 进化分支由生活方式决定，比如常跑步 → 敏捷型，常练力量 → 坦克型，作息规律 → 稀有形态。
- 社交：加好友、异步对战（服务器用随机种子算出结果，两边播放同一段动画）、交换（部分宠物要交换才能进化）、碰手腕见面（两块表同一时刻的加速度峰值 + 位置在服务器上匹配）、情侣或好友合作任务。
- 对战要有属性相克和技能，不能纯比数值。
- AI：宠物用自己的口吻说出健康数据（"昨晚只睡了 5 小时，我也没劲"）、每周来信、跟对战挂钩（"想赢下周的对战，这周要睡够 7 小时"）、对战解说。不做医疗诊断。
- 宠物不会死，最多生病或闹脾气；换设备也能延续，数据可备份。
- 参考 Claude Code `/buddy`（2026 年愚人节上线、4 月 9 日下线，有物种、稀有度、性格属性、闪光变种、帽子，下线后用户"哀悼"）：证明用户很快会对宠物产生感情，稀有度和闪光变种能制造收集欲。

## 产品形态（已定）
- iPhone 是主战场：图鉴、对战、好友、AI 来信、限时活动。
- 手表负责随身陪伴和采集数据：抬腕看宠物、表盘小组件、通知、碰手腕。
- 原因：调研发现纯手表宠物没有一个做大，手表 App 几乎没有自然流量。

## 美术与版权（已定）
- 像素风。宠物 32×32 或 48×48，表盘图标 16×16 或 24×24，固定 16 到 32 色调色板，整数倍放大且关闭平滑插值。
- 可考虑差异化方向：复古液晶屏风格，或像素角色 + 现代特效。
- AI 生成的像素图需要在 Aseprite 里按网格手修。
- 版权：角色、名字、画风全部原创；不用 "Pokémon / Poké-" 这类字眼，宣传也不提宝可梦；不做"投掷道具捕捉"和"骑乘宠物"（任天堂告幻兽帕鲁用的是这类专利）；孵蛋、养成、交换、对战属于通用机制，风险低。赚钱后请游戏知识产权律师过一遍。

## 收费（已定）
- 订阅才能用：月费约 4.99 美元，年费 29.99 到 39.99 美元，国区单独定价（比如月费 18 元、年费 98 元）。
- 必须有 7 天免费试用。
- 为照顾社交拉新：会员邀请的朋友额外获得试用、情侣或家庭套餐、试用结束后宠物"冬眠"而不是删除。
- 额外道具：外观、皮肤、表盘主题、宠物小窝装饰、限时活动的限定蛋和闪光外观、额外栏位、加速孵蛋等方便类道具。
- 原则：钱只能买"好看"和"方便"，不能买战斗力。不放广告。
- App 内订阅必须走苹果内购，不能用 Stripe 这类第三方支付。
- 第一版只做订阅，道具等有几百个付费用户之后再根据反馈加。

## 竞品调研
- Apple Watch 宠物：Watch Pet（Kooapps，约 23.8 万安装，月活约 7,300 且在下滑，广告 + 内购）、PetPock（2.79 万安装，月活 1,900，7 成收入靠广告，VIP 一周 0.99 / 一年 9.99 / 终身 4.99 美元）、Belly（像素猫，有"广场"加好友，700 安装）、WatchieBesti（买断 2.99 到 3.99 美元）、Tamawatchi、Pixel Paws、Peggy Cat、Poki、TameWatch、nomi。月收入估算全部低于 1 万美元。
- 健康驱动宠物：Hatchiko、Pet-Jam、FitPets、HealthMon（好友码）、Habitvs（宠物 Kova 的心情由睡眠、HRV、心率等决定，每周写信，最接近我们的思路）、Pomagotchi（iPhone 本地生成宠物性格）。都没跑出来。
- 做大的参照：Pokémon Sleep（3 年收入 2.349 亿美元，过去一年平均每月约 570 万美元；高级通行证 1 个月 9.99 / 6 个月 49.99 美元，另卖钻石；靠限时传说宝可梦活动拉收入）、Finch（月收入约 100 万美元，约 122 万条评价、4.93 分；Finch Plus 每月 9.99 / 每年 69.99 美元左右，免费版也能完整养成）。
- 大盘：拓麻歌子全球出货突破 1 亿台，新款 Paradise 受 20 到 30 岁成年人欢迎；万代 2026 年 8 月开始预售戒指款 Tamagotchi ring。
- 苹果自己有 watchOS 26 的 Workout Buddy（AI 健身教练），我们不拼健康分析的专业度。
- 差异化空位：没人同时做"健康数据决定属性和进化 + 好友对战 / 交换 + AI 性格"。
- 建议下载体验：Pokémon Sleep、Finch、Habitvs、Watch Pet、Belly，至少连续用一周，重点观察"第几天开始不想打开，为什么"。

## 开发者情况
- 用 Windows 开发，没有 Mac；有一块 Apple Watch 可以测试。
- 熟悉 Node.js / TypeScript；有自己的 new-api 多模型网关，可以用来接 AI。

## 技术方案（已定）
- 手表端只能用 Swift / SwiftUI（Flutter、React Native、Unity 都做不了 watchOS 界面）。
- 游戏核心逻辑全部放在后端，用 TypeScript 写，以服务器为准；手表端只做读取 HealthKit、上传数据、显示结果、播放像素动画。
- 后端用 Supabase 或 Cloudflare Workers，不要绑死 CloudKit（方便以后跨平台）。
- 开发顺序：
  1. Windows 阶段：TypeScript 核心逻辑（属性换算、心情、进化、对战结算）+ 单元测试和批量模拟调数值；后端（账号、存档、好友、对战、订阅校验接口）；AI 宠物人设和提示词；手表尺寸的网页原型，带假健康数据面板，拿给朋友试玩。
  2. 有 Mac 之后：写 watchOS / iPhone 端（HealthKit、像素动画、表盘小组件、通知、内购）。
- 没 Mac 时的过渡方案：
  - Devin 有云端 Mac（2026 年 9 月起），预装 Xcode 和 iOS 模拟器，但没确认有没有 watchOS 模拟器；可以打包上传到 TestFlight 装到真手表。
  - GitHub Actions 的 macOS 机器：公开仓库免费；私有仓库每月 2,000 免费分钟但 macOS 按 10 倍扣，约等于 200 分钟，大概够打 15 到 20 次包；超出后每分钟 0.062 美元。
  - 租云端 Mac 用远程桌面跑 Xcode 和手表模拟器：Scaleway 起步每小时约 0.11 欧元（据说最少租 24 小时），Rentamac 独享 M4 每天 3.3 美元起。
  - Windows 上可以装官方 Swift 工具链 + VS Code 写纯逻辑代码；远程日志（自己的服务器或 Sentry）、App 内调试页面、假数据开关，用来弥补看不到实时日志的问题。
- 硬件相关备注：高频运动数据接口 CMBatchedSensorManager（watchOS 10+，加速度 800Hz、姿态 200Hz）只在开启 HealthKit 体能训练时可用；苹果本地 AI 模型（Foundation Models）跑在 iPhone 上，国区 Apple Intelligence 能否使用待确认，不行就接云端 API（国内需要 AI 备案）。
- 以后跨平台优先级：Wear OS → 华为鸿蒙手表 → 佳明 → 小米，现在先不考虑。

## 还没定的（下一步要规划）
1. 世界观和主题：宠物到底是什么，为什么靠"身体能量"成长
2. 第一批宠物（先 3 到 5 只）和进化分支
3. 健康数据换算成属性的具体公式和数值
4. 对战规则：属性相克、技能、回合结算公式
5. AI 宠物的性格设定和说话风格
6. MVP 范围：第一版做什么、不做什么
   - 已有的建议：第一版先做单只宠物 + 健康数据驱动属性 + AI 说话，验证用户是否愿意每天打开；第二步再上好友和对战；碰手腕放第三步配合推广。
