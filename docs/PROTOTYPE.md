# 网页原型：功能清单和怎么试

运行：`pnpm web`，打开 http://127.0.0.1:5173 。左边是手表，中间是手机，右边是"假健康数据"面板（原型专用）。
代码分三层：`packages/engine`（数值规则：成长、进化、对战）→ `packages/game`（一个玩家的状态和每天发生什么：早晨卡片、小惊喜、Boss、切磋、通知文案、作息，**以后服务器直接用这一层**）→ `apps/web`（原型界面，加上模拟人设、模拟好友、浏览器存档）。测试：`pnpm test`（引擎 + 原型逻辑），`pnpm typecheck`。

## 辅助功能

- 减弱动态效果（跟随系统，右侧也能手动开）；宠物图都有朗读文字。见 [07 辅助功能](design/07-打磨规范.md)。

## 已知问题和还没做

- 宠物的话都是模板，**还没接 AI**（按你的要求先不接）。
- 美术是程序画的，正式版要按 [07 §5](design/07-打磨规范.md) 用 Aseprite 重画。
- 好友是模拟的；真正的好友系统、好友码、服务器都还没做。
- 个别固定好友对局仍会一边倒（属性和成长阶段都不利时 7–16% 胜率），靠卡片提示和学克制技能缓解，见 [04](design/04-对战.md)。
- HealthKit 后台推送的延迟、手表上的真实性能，都要等有 Mac 和真机再测。
