# 06 MVP 与付费

> 相关：[01 核心玩法](01-核心玩法.md) · [决策记录](../DECISIONS.md) · 收费原则见 [HANDOFF.md](../HANDOFF.md) 的"收费"一节

## 目标

只验证一件事：**用户会不会因为这只宠物每天抬腕、每天打开 App。**

## 先做网页原型（Windows 上就能做）

手表尺寸的网页 + 假健康数据面板（拖滑块改步数、睡眠等，能"快进"看进度条和进化），给 10–20 个朋友试玩，先验证"宠物有没有吸引力、说话有没有意思"。网页原型和后端共用同一套 TypeScript 核心逻辑。

## 第一版 App（有 Mac 之后）

**做：**
- 草 / 水 / 火三选一、当场孵化、进化进度条 + 目标形态、闪光变种
- 健康数据第 1–3 层（见 [03 健康数据](03-健康数据.md)）→ 回响、属性、进化
- 宠物心情、每日 AI 短句、每天 3 句短对话、记忆、每周来信
- 每日试炼 + 简化版野怪收集和图鉴 + 周 Boss
- 手表：抬腕看宠物、表盘小组件、每天 1–2 条通知
- iPhone：宠物详情、进度条、属性变化图、图鉴、数据透明页
- 免费版完整养成 + Pulseling Plus 会员（7 天试用）
- 账号和云端存档；宠物和野怪图片由服务器下发

**不做：**
- 好友、好友对战、交换、碰手腕（第二、三步）
- 道具商城（几百个付费用户之后）
- 养第二只宠物、捡蛋孵化、宠物小窝
- 安卓和其他品牌手表
- 国区（版号、AI 备案、数据出境以后专门处理）

## 收费：免费增值（2026-11-21 起，取代"只能订阅才能玩"）

**免费版能完整养成；会员买的是"它会说话、更多陪伴、更深的数据、更多外观"。** 参照 Pokémon Sleep（核心免费）和 Finch（免费版也能完整养成）。只能订阅时，好友对战、合作都要求对方也付费，传播会断。

| | 免费 | Pulseling Plus |
|---|---|---|
| 孵化、每天成长、早晨卡片、小惊喜、心愿、改变明天的事件、探险 | ✅ | ✅ |
| 野怪遭遇和图鉴、全部进化形态、稀有度升档、闪光 | ✅ | ✅ |
| 手表 App、表盘小组件、通知 | ✅ | ✅ |
| 周 Boss、好友（合作 Boss、切磋） | ✅ | ✅，回放多一段 AI 解说 |
| 宠物说的话 | 固定模板（按数据和性格挑句子） | AI：抬腕一句话、每天 3 句对话、记忆 |
| 每周 | 周报卡片（本周数字 + 模板文案） | AI 写的完整来信 |
| 研究笔记（见 [01](01-核心玩法.md)） | 本周数据 | 全部历史、趋势图、月报和年报 |
| 第二只伙伴（第二步） | — | ✅ |
| 外观 | 稀有度、图鉴里程碑、活动给的 | 每月一件会员外观 + 表盘主题 |

- **钱仍然不买战斗力**：会员在对战里只多一段解说。第二只伙伴和主宠吃同一份数据，对战只带主宠。
- **AI 只给会员和试用期**，AI 成本随收入增长，不会被免费用户拖垮。
- **价格不变**：月费约 4.99 美元，年费 29.99–39.99 美元，7 天免费试用，走苹果内购，不放广告。

### 什么时候邀请试用

不弹硬付费墙，在"会员最有用"的时刻轻轻邀请，每 3 天最多一次，不打断早晨卡片：

| 时刻 | 邀请 |
|---|---|
| 第 3 天（它第一次"想说话"） | 宠物气泡卡住："我有好多话想说……"→"开启 7 天试用，让它开口说话" |
| 第 6 天（第一次周 Boss 和周报） | 周报卡片下面放一封"信封"："想看它亲手写的信吗？" |
| 第一次进化当天 | "它想跟你讲讲这两周" |

- 试用结束不扣任何东西：宠物照常长，只是说话回到模板；**记忆一直保留**，再开会员它还记得你。
- 不再有"冬眠"。原来的冬眠是为了逼订阅，免费增值下不需要。
- 上线后 A/B 测试第一次邀请的时机（第 3 天 / 第 6 天）。

## 账号

- 首次打开自动生成匿名账号，不要求登录，30 秒内就能看到孵化。
- 第 3 天或第一次加好友时，邀请"通过 Apple 登录"，把匿名账号升级为正式账号："登录保存它，换手机也不会丢"。不跟付费绑在一起。
- 只支持"通过 Apple 登录"一种方式：一键、可隐藏邮箱、不用做密码。
- 订阅绑定 Apple ID，没绑账号也能"恢复购买"找回会员身份；宠物存档需要账号。
- 前 3 天未绑定时删 App 会丢档，损失很小，可接受。

## 冬眠（已取消）

原设计：不付费时宠物冬眠、不成长。2026-11-21 改为免费增值后取消（决策第 68 条）。"好久没打开 App"的回归体验保留：回来时宠物讲讲这段时间你的样子（会员用 AI，免费用模板），送一份小礼物。

## 不做游戏货币

MVP 不做金币、钻石之类的货币，奖励都直接给东西：
- 打赢野怪 → 得到这只野怪 + 一个技能
- 打赢周 Boss → 直接加成长值
- 重复遇到野怪 → 闪光碎片，攒够换一次闪光
- 外观 → 以后直接用真钱买（苹果内购）

理由：做了什么就得到什么，好懂；不用做商店和物价平衡；不会让人怀疑"钱能买战斗力"。以后如果要加货币（比如宠物小窝装饰），只做"只能靠健康赚、不能花钱买"的那种。

### 碰手腕（第三步）

- 原理同 Bump：两人打开"碰一碰"页面碰一下 → 两块表各传"加速度峰值时间 + 大概位置" → 服务器配对时间差 0.5 秒内、位置相近的记录 → 双方确认。
- 技术难度中等，难在测试：需要两块真手表和两个账号，开发前准备一块二手 Apple Watch。
- 同时做手机上的备用方式（好友码 / 扫码）。
- 超宽带测距、NFC 暂不考虑（前者复杂且不支持老款，后者苹果不开放）。

## 判断第一版成不成功（参考线）

- 次日留存 ≥ 50%，7 日留存 ≥ 25%，30 日留存 ≥ 12%
- 试用转付费 ≥ 10%；月活跃用户里会员占比 3–5%（免费增值常见范围，上线后按实际调）
- 用户主动截图分享宠物 / 来信的比例（"15 秒视频让人哇"的信号）
