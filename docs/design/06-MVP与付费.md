# 06 MVP 与付费

> 相关：[01 核心玩法](01-核心玩法.md) · [决策记录](../DECISIONS.md) · 收费原则见 [HANDOFF.md](../HANDOFF.md) 的"收费"一节

## 目标

只验证一件事：**用户会不会因为这只宠物每天抬腕、每天打开 App。**

## 先做网页原型（Windows 上就能做）

手表尺寸的网页 + 假健康数据面板（拖滑块改步数、睡眠等，能"快进"看进度条和进化），给 10–20 个朋友试玩，先验证"宠物有没有吸引力、说话有没有意思"。网页原型和后端共用同一套 TypeScript 核心逻辑。

## 第一版 App（有 Mac 之后）

**做：**
- 草 / 水 / 火三选一、当场孵化、进化进度条 + 目标形态、闪光变种
- 健康数据第 1–3 层（见 [03 健康数据](03-健康数据.md)）→ 回响、属性、进化
- 宠物心情、每日 AI 短句、每天 3 句短对话、记忆、每周来信
- 每日试炼 + 简化版野怪收集和图鉴 + 周 Boss
- 手表：抬腕看宠物、表盘小组件、每天 1–2 条通知
- iPhone：宠物详情、进度条、属性变化图、图鉴、数据透明页
- 订阅 + 7 天试用 + 冬眠机制
- 账号和云端存档；宠物和野怪图片由服务器下发

**不做：**
- 好友、好友对战、交换、碰手腕（第二、三步）
- 道具商城（几百个付费用户之后）
- 养第二只宠物、捡蛋孵化、宠物小窝
- 安卓和其他品牌手表
- 国区（版号、AI 备案、数据出境以后专门处理）

## 付费墙：孵化后免费玩 3 天，第 3 天弹

流程：选草/水/火 → 授权健康数据 → 当场孵化 → 免费玩 3 天（开奖、野怪、说话都能用）→ 第 3 天付费墙："进化进度 20%，它会变成这样……（显示剪影）开启 7 天免费试用，陪它继续长大" → 试用第 3–10 天 → 第 9 天提醒 → 第 10 天开始扣费。

- 已经涨了一截的进度条本身就是付费理由（"已有进度效应"）。
- 付费墙写清楚"试用结束前一天提醒你，可以随时取消"。
- 不开试用也不删宠物：宠物进入冬眠，每次打开都能看到它在睡觉，随时开试用叫醒它。
- 行业数据里"一打开就要求订阅"的下载→付费率往往更高，上线后做 A/B 测试（孵化后马上弹 vs 第 3 天弹）。
- 订阅必须走苹果内购。价格：月费约 4.99 美元、年费 29.99–39.99 美元；钱只能买"好看"和"方便"，不能买战斗力；不放广告。

## 账号

- 首次打开自动生成匿名账号，不要求登录，30 秒内就能看到孵化。
- 第 3 天开试用时顺便"通过 Apple 登录"，把匿名账号升级为正式账号："登录保存它，换手机也不会丢"。
- 只支持"通过 Apple 登录"一种方式：一键、可隐藏邮箱、不用做密码。
- 订阅绑定 Apple ID，没绑账号也能"恢复购买"找回会员身份；宠物存档需要账号。
- 前 3 天未绑定时删 App 会丢档，损失很小，可接受。

## 冬眠

- 没开试用或订阅过期 → 宠物冬眠。宠物、图鉴、技能、记忆全部保留，什么都不丢。
- **冬眠期间不算成长**：进度条不涨、不遇野怪、不打 Boss。否则订阅失去意义，用户会"需要时才订一个月"。
- **叫醒时温暖不惩罚**：宠物用 AI 说出它"梦到"的你这段时间的样子（会读这段时间的数据，但只用来聊天，不加成长），并送一份固定小礼物（少量成长值）。
- 个人基线照常用最近 28 天历史，叫醒后数据马上就是准的。

## 不做游戏货币

MVP 不做金币、钻石之类的货币，奖励都直接给东西：
- 打赢野怪 → 得到这只野怪 + 一个技能
- 打赢周 Boss → 直接加成长值
- 重复遇到野怪 → 闪光碎片，攒够换一次闪光
- 外观 → 以后直接用真钱买（苹果内购）

理由：做了什么就得到什么，好懂；不用做商店和物价平衡；不会让人怀疑"钱能买战斗力"。以后如果要加货币（比如宠物小窝装饰），只做"只能靠健康赚、不能花钱买"的那种。

## 后续节奏

| 阶段 | 内容 | 上线条件 |
|---|---|---|
| 第二步 | 好友 + 异步好友对战 + 开放更多第二属性（电、地面、暗影）+ 交换进化 + 第二只伙伴（活跃满 30 天解锁，见 02）+ 每周挑战（见 07 第 2 节） | 第一版 7 日留存达标 |
| 第三步 | 碰手腕见面 + 情侣 / 好友合作任务 + 限时活动 | 配合推广，拍 15 秒短视频 |

### 碰手腕（第三步）

- 原理同 Bump：两人打开"碰一碰"页面碰一下 → 两块表各传"加速度峰值时间 + 大概位置" → 服务器配对时间差 0.5 秒内、位置相近的记录 → 双方确认。
- 技术难度中等，难在测试：需要两块真手表和两个账号，开发前准备一块二手 Apple Watch。
- 同时做手机上的备用方式（好友码 / 扫码）。
- 超宽带测距、NFC 暂不考虑（前者复杂且不支持老款，后者苹果不开放）。

## 判断第一版成不成功（参考线）

- 次日留存 ≥ 50%，7 日留存 ≥ 25%，30 日留存 ≥ 12%
- 试用转付费 ≥ 10%
- 用户主动截图分享宠物 / 来信的比例（"15 秒视频让人哇"的信号）
