# 02 宠物与进化

> 相关：[03 健康数据](03-健康数据.md)（回响怎么算）· [04 对战](04-对战.md)（相克表）· [决策记录](../DECISIONS.md)

## 属性（9 个）

| 属性 | 对应的生活方式 / 数据来源（HealthKit） | 主要加成 |
|---|---|---|
| 草 | 日常步数、户外步行 | 体力 |
| 水 | 睡眠时长、作息规律 | 恢复 |
| 暗影 | 深睡比例、夜间 HRV | 恢复 |
| 火 | 活动能量、高强度运动 | 攻击 |
| 战斗 | 力量训练 | 攻击 |
| 飞行 | 跑步、骑行等有氧 | 速度 |
| 电 | 高心率区间分钟、间歇训练 | 速度 |
| 地面 | 连续打卡天数、爬楼 | 防御 |
| 龙（稀有） | 多项同时明显高于平时 | 无偏向 |

- 龙只是"稀有"，不是"更强"：龙系基础属性总和跟其他属性一样，稀有只体现在收集和外观上。
- 只借用"属性"这个通用机制，不照搬赛尔号的相克表、精灵名字和形象。

## 初始宠物

开局**三选一：草、水、火**，每系一个物种（形象待美术定稿，概念图见 [09](09-美术生图提示词.md)）：

| 属性 | 物种 | 标志特征 | 性格印象 |
|---|---|---|---|
| 火 | 火兔 | 耳尖和尾巴是小火苗 | 活泼、有点小得意 |
| 水 | 鸭嘴兽 | 头顶水滴冠，尾巴是流动的水 | 憨、慢半拍 |
| 草 | 松鼠 | 尾巴是一整片大叶子，小龅牙 | 机灵、爱囤东西 |

### 为什么只给 3 个

- **美术成本**：每个初始物种有幼体、成长体和 5 种成熟体，共 7 个形态。3 个物种是 21 个形态，6 个就是 42 个。
- **选了不能换**：宠物绑定心跳、不能重开。选项越多越容易后悔；3 个能马上做决定，选完有归属感。
- **"多"放在后面**：5 种成熟体、可以养上去的稀有度、闪光、野怪图鉴、第二只伙伴，都是开局之后的惊喜。

### 蛋会"选你"

选蛋时已经读取了过去 28 天的健康数据，三个蛋里倾向最高的那一系会发光，并说一句理由：

- 火：活动能量、高强度运动多（"你上周烧掉的热量，让这颗蛋暖烘烘的"）
- 水：睡眠时长和作息规律（"你睡得很规律，这颗蛋在轻轻冒泡"）
- 草：日常步数（"你每天都走很多路，这颗蛋发芽了"）

玩家仍可以选任意一个蛋，推荐只是让三选一看起来像"为你准备的"。数据不足或拒绝授权时不推荐，三个蛋一样亮。

### 同一个物种，每只都不一样

用调色和配件层实现，不额外画图：

- **花纹**：蛋壳花纹和身上的小花纹跟过去 28 天的数据挂钩（已有设计，跑步多有风纹）。
- **色调**：在属性主色附近小幅偏移（由账号种子决定），同系的两只放在一起能看出不同。
- **一个小特征**：从一组"小缺陷"里抽一个，比如一撮呆毛、一只耳朵的火苗小一点、叶尾有个虫咬缺口。
- **性格**：孵化时抽，只影响说话口吻和待机动作（见 [05](05-AI宠物.md)）。

### 第二只伙伴（第一版之后）

- 累计活跃满 30 天，可以从另外两系里再领一只。
- 两只吃同一份健康数据，成长同步，不用分配；手表上一次只显示一只"主宠"，随时可以换，对战带主宠出场。
- 给付费用户一个中期目标，也解决"开局只能选一个"的遗憾。

### 初始阵容怎么扩充

- 开局固定这三只，方便新手引导和平衡。
- 之后每季度新增一条初始进化线，进入"第二只伙伴"的可选池和限时活动；新用户开局仍只看三只。
- 落选的概念（例如火獾）改成野怪；跟现有 IP 撞车的造型（刺猬背草、蓝色小象）不用。

## 主宠稀有度（只影响外观，可以养上去）

孵化时随机抽**起始**稀有度，借鉴 Claude Code 的 `/buddy`。起始稀有度由账号种子决定，不能重抽（宠物绑定你的心跳）；但它只是起点，可以靠健康习惯往上升。

| 稀有度 | 概率 | 外观（每档在下一档基础上加一层） |
|---|---|---|
| 普通 | 60% | 基础造型 |
| 不普通 | 25% | + 随机一个配饰（帽子、围巾、护目镜等） |
| 稀有 | 10% | + 特殊眼睛 |
| 史诗 | 4% | + 待机特效（身边飘花瓣、火花、泡泡等） |
| 传说 | 1% | + 专属光环、专属卡片边框 |

### 稀有度可以养上去

60% 的人孵出"普通"，如果稀有度定死，第一眼就会觉得"这号废了"，而且孵化就在付费墙之前。所以稀有度是起点，不是终点：

| 怎么升 | 条件 | 次数 |
|---|---|---|
| 第一次进化时 | 最近 14 天至少一项运动习惯达标（火、战斗、飞行、电任一倾向 ≥ 0.6，例如每周有氧约 90 分钟或力量约 36 分钟） | +1 档，一次 |
| 第二次进化时 | 进化成飞行、战斗、地面或龙形态（达成了该形态的条件）；选纯系强化兜底不升 | +1 档，一次 |
| 累计活跃 180 天 | 戴着手表且有活动的天数累计到 180，约半年（不要求连续，漏一天不清零，符合"只加不减"） | +1 档，一次 |

- 靠努力**最多比孵化时高 2 档**，最高到**史诗**；**传说只能孵化时抽到**。所以普通最多养到稀有，不普通最多到史诗，孵化运气仍然有意义。
- 模拟结果：孵化时普通的人，120 天后 70% 升了档；一年后一半的宠物是稀有（见 [模拟结果](../SIMULATION.md)）。
- 每升一档加上那一档的外观层，原有外观保留。
- 普通宠物坚持下来可以养成稀有甚至史诗，所以普通不是"废号"，而是"还没养成"。孵化时宠物可以说"我现在还很普通，但只要你坚持，我会越来越闪亮"。
- 卡片上同时显示起始稀有度和当前稀有度，"从普通养到史诗"本身就值得炫耀。
- 配饰、特效以后也能从图鉴里程碑、限时活动获得，不只靠稀有度。

### 其他规则

- **只影响外观，不影响任何战斗数值**（跟性格同一原则：宠物不能重开，运气不该决定战斗力）。/buddy 的稀有度会提高属性，但它没有对战，所以没关系；我们有，所以不能照搬。
- 闪光照旧独立抽（1/64），"传说 + 闪光"约 1/6400。
- 图鉴和宠物卡片上显示稀有度，方便截图分享。
- 以后的付费外观、限定配饰沿用同一套视觉层（配饰 / 眼睛 / 特效 / 光环），符合"钱只买好看"。
- 代码：`packages/engine/src/rarity.ts`，配饰等目前是占位 id，等美术出图后替换。

## 成长阶段

| 阶段 | 什么时候 | 说明 |
|---|---|---|
| 蛋 | 第 0 天，当场孵化 | 选草/水/火 → 授权健康数据 → 读取过去 28 天历史 → 蛋吸收"过去一个月的回响"当场孵化，第一句话就提到真实数据（如"你上周跑了 3 次！"）。蛋壳花纹跟历史数据挂钩（跑步多有风纹）。历史数据不足时照常孵化，第一句话改为"我们一起从今天开始吧"。"戴着手表睡一晚"作为第 1 天晚上的第一个小任务，第二天早上第一次开奖 |
| 幼体 | 第 0 天起 | 本系单属性。每天有小变化（长小角、换花纹、学新待机动作），用配件和调色实现，不用每次画新图 |
| 成长体 | 进度条填满，正常约 2 周（最少 10 天） | 仍是本系单属性，外形变化，解锁新技能 |
| 成熟体 | 进度条再次填满（约 2 个月）**且**达到目标形态的条件 | 本系 + 第二属性 |

### 进化进度条

- 进化不按天数，按**进度条**：每天的成长值往里填，填满才能进化。越健康填得越快——"你越健康，它进化越快"。
- 第一次进化正常约 2 周，最少 10 天；第二次约 2 个月。进化是攒出来的大事件。
- 进度条一直显示在宠物页面，加上幼体每天的小变化，保证每天早上都有东西看。

### 提前知道会变成什么样 + 想要哪个就得达标

- 从孵化起就能看到成长体的剪影。
- 成熟体有 5 种可能，图鉴里显示 5 个剪影和各自的**进化条件**，玩家可以把其中一个设为"目标形态"。
- 条件看最近 21 天的**生活方式倾向**（0–1，对照 WHO 等健康指南的绝对标准，见 [03 健康数据](03-健康数据.md)），不跟自己的平时水平比：
  - 本系 + 飞行：飞行倾向 ≥ 0.6（约每周有氧 90 分钟以上）
  - 本系 + 战斗：战斗倾向 ≥ 0.6（约每周力量训练 36 分钟以上）
  - 本系 + 地面：地面倾向 ≥ 0.6（每周大多数天都有活动，比如日均 5,000 步以上，并常爬楼）
  - 同时满足几种时由玩家选（原来要求"在第二属性里最高"，加入地面后，常跑步的人地面倾向往往也很高，反而进化不成飞行，所以去掉了）
  - 纯系强化：没有条件，永远可选
  - 本系 + 龙（稀有）：最近 14 天至少 4 种倾向 ≥ 0.9，其中至少 2 种是运动类（火、战斗、飞行、电）
- **为什么不跟自己比：** 写引擎时发现，坚持跑步好几年的人每周跑量稳定，"比平时多"的分数一直在 0 附近，按"跟自己比"永远变不成飞行形态。进化形态代表"你是什么样的人"，所以用绝对标准；"成长快慢"和"状态加成"仍然跟自己比，保证对普通人公平。
- 进度条满了但目标条件没达到：宠物进入"蓄力中"，页面写明还差什么（如"最近 21 天再多跑 2 次"）。玩家也可以随时"现在就进化"，变成当前已达标的形态；纯系强化永远可选，作为兜底，不会卡死。
- 进化变成"选目标 → 为它改变生活 → 达标后进化"，健康数据和想要的结果直接挂钩。

### 试用期里

试用期（第 3–10 天）不会进化，但会经历：每天早上开奖、遇到野怪、幼体每天的小变化、第一个周 Boss 和第一封周信、进度条涨到一半左右。第一次进化（约第 14 天）落在付费后不久，帮助留住刚付费的人。

## MVP 的第一批形态

第二属性先开**飞行（有氧）、战斗（力量）、地面（规律活跃）**，加上纯系强化和龙：

| 初始 | 幼体 | 成长体 | 成熟体（5 选 1） |
|---|---|---|---|
| 草 | 1 | 1 | 草飞行 / 草战斗 / 草地面 / 纯草强化 / 草龙 |
| 水 | 1 | 1 | 水飞行 / 水战斗 / 水地面 / 纯水强化 / 水龙 |
| 火 | 1 | 1 | 火飞行 / 火战斗 / 火地面 / 纯火强化 / 火龙 |

- 共 21 个形态。电、暗影作为第二属性随版本陆续开放。
- 加地面的原因：只有飞行和战斗时，久坐和走路的人（约一半用户）最后只能走纯系兜底，模拟中纯系占 48%；加了地面后降到 23%，走路的人自然会变成地面形态。
- **闪光变种：** 孵化时 1/64 概率，只换调色板，不影响属性。
- 第二步再加入"必须交换才能进化"的形态。

### 美术上线节奏

- 上线时只需画好 3 只 × 幼体（含每日小变化的配件）、成长体 = 6 张，加 18 只野怪；成熟体的剪影和进化条件也要上线时就准备好。
- 15 个成熟体在上线后 6 周内补齐（最早的用户约 2 个月才会第二次进化）。
- 所有宠物和野怪图片由服务器下发，不打包进 App，补形态、加野怪、上活动都不用重新提交审核。
- 兜底：某个成熟体还没画好时，先进化成纯系强化，新形态上线后给这批用户补一次进化。

## 野怪与图鉴（MVP 简化版收集）

野怪只收集、不养：没有等级、不进化、不上场对战。作用是让每天早上有东西可开；收服后能教主宠一个该属性的技能（见 [04 对战](04-对战.md)）。

- **遇到：** 每天早上结算一次，概率 30%。连续 4 天没遇到，第 5 天必定遇到。
- **属性跟生活方式挂钩：** 野怪属性按最近的生活方式倾向和前一天回响加权抽取（具体权重在写遭遇模块时定）。跑步多容易遇到飞行、电系，睡得好容易遇到水、暗影系。想收集某个属性，就去过那种生活。
- **收服：** 当天的每日试炼就是跟这只野怪打（自动对战）。赢了收进图鉴；输了野怪跑掉，图鉴里留一个剪影，之后还可能再遇到。
- **稀有度权重：** 普通 70%、稀有 25%、史诗 5%（18 只里约 9 / 6 / 3 只）。跟主宠共用同一套 5 档名称；"不普通"和"传说"野怪留给限时活动。
- **收集速度目标：** 第一个月收 6–8 只，3 个月收一半左右，全部收齐要一年以上。具体概率用批量模拟对着这个目标调。
- **重复遇到：** 打赢给一点成长值和"闪光碎片"（攒够换一次闪光机会）。
- **闪光：** 任何野怪都有 1/64 概率是闪光版，图鉴单独记录。龙系野怪平时很少见（权重和其他属性的基础值一样，约占遭遇的 3–4%），满足龙的条件时概率提高到约 5 倍，以后限时活动再提高。原来只有满足龙的条件才出现，结果只有全能型的人能收齐图鉴。
- **数量：** MVP 先做 18 只左右（9 个属性各 2 只），每只一张图加简单待机动画。
- **不会"收完"：** 每季度或限时活动加新野怪。
- **图鉴奖励：** 收集到一定数量解锁表盘主题、称号等，不给战斗力。

## 美术

- **赛璐璐卡通插画，不用像素。** 原型里试过像素和用代码画的矢量图，质感都不够（见决策第 61 条）。干净的线稿、深色同色系描边、一层硬边阴影，每只 3–4 个主色。
- **流程**：AI 生图出概念（提示词见 [09](09-美术生图提示词.md)）→ 挑方向 → 插画师定稿并补齐进化和表情。
- 属性靠主色一眼区分：火红、水蓝、草绿、电黄、暗影紫……
- 闪光变种只换配色。
- 缩到 40px（表盘复杂功能）也要能认出：剪影简单，标志特征够大。
- 复古液晶屏（4 色绿屏）不做默认，做成付费表盘皮肤。
- AI 生成的像素图要在 Aseprite 里按网格手修；角色、名字、画风全部原创。
