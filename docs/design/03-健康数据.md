## 怎么拿：明细在手机上算，只上传结果

| 层 | 在手机上读（不上传） | 上传 | 用途 | 阶段 |
|---|---|---|---|---|
| 1. 每日汇总 | 步数、站立、活动能量、爬楼 | 每天总数 | 草、火、地面回响 | MVP |
| 2. 手机上算的特征 | 心率明细、睡眠各阶段、HRV 明细 | 高心率区间分钟、深睡比例、入睡时间、夜间 HRV 平均、静息心率 | 电、暗影、水回响 | MVP |
| 3. 事件摘要 | 每次运动记录 | 每次一行：类型、开始时间、时长、距离、平均心率（不含 GPS） | AI 说出具体事件（"周三晚上那 5 公里"），对战回放讲具体哪天 | MVP |
| 4. 特殊功能 | 加速度传感器 | 只传峰值时间点 | 碰手腕 | 第三步 |

- **防作弊：** 带"手动录入"标记的记录不计入回响；单日封顶。
- **步数去重：** 用 HealthKit 统计查询（自动合并 iPhone 和手表），不自己相加。
- **没戴手表：** 夜里没有任何心率记录就判定为没戴，宠物"在睡觉"，不扣任何东西。
- **后台同步：** HealthKit 后台通知 → iPhone 自动计算并上传，不用打开 App 早上也能"开奖"。
- **透明页：** App 内列出原样上传的数据 + "删除全部数据"按钮。

## 合规

- **苹果审核：** 健康数据只能用于 App 自己的功能，不能用于广告、营销或卖给第三方；必须有隐私政策；授权弹窗写清用途；不往"健康"App 写假数据（我们只读不写）。
- **第三方 AI：** 把健康汇总发给第三方大模型前，要单独弹窗告知并获得同意。苹果本地的 Foundation Models 不算第三方。
- **最小必要：** 只收集功能用得上的数据；以后有功能需要明细，再补隐私政策并单独征得同意。
- **国区：** MVP 先只上海外区。国区要处理游戏版号（带内购的游戏需要，个人开发者基本拿不到，最大风险）、AI 备案、健康数据属于敏感个人信息需单独同意、服务器在海外时的数据出境。

## 两层结构：成长值 + 状态

- **成长值（永久）：** 只涨不跌，代表"养了多久、多用心"，决定基础属性，同时填进化进度条。
- **状态（临时，只加不减）：** 由最近 3 天的"当天质量"（0.5 × 睡眠回响 + 0.5 × 最高的运动回响，负数按 0 算）平均决定，是 1.00–1.25 的系数，**只乘在对战伤害上**（乘在全部属性上会叠加成约 +50% 战斗力，见 [04 对战](04-对战.md)）。睡得好、动得多就有加成；偷懒只是没加成，永远不低于正常值。

## 个人基线

- 每项指标取**最近 28 天的中位数**作为基线（中位数比平均数抗异常值，比如偶尔一次马拉松）。
- 首次打开直接读取 HealthKit 过去 28 天历史作为基线，大多数用户第一天就有真实基线。
- 历史数据不够 7 天时，用人群默认值和自己的数据按天数混合：`基线 = (n×自己中位数 + (7−n)×默认值) / 7`。
- 基线有下限（比如步数不低于 2,000），防止"基线极低，随便动动就暴涨"。

## 每日回响

对每项指标算一个跟自己比的分数：

```
比值 r = 今天 / 基线
分数 s = clamp((r − 1) / 0.5, −1, +1)      // 比平时多 50% 就满分，少 50% 就最低
```

例外（不是越多越好）：
- **睡眠：** 用绝对区间打分，7–9 小时满分，偏离越多越低。再加"入睡时间跟平时差多少"的规律分。
- **静息心率：** 越低越好，方向反过来。
- **HRV：** 跟自己基线比，越高越好，只看 7 天平均（单日波动太大）。

每种属性的回响 = 对应数据分数的加权和：

| 回响 | 用到的数据和权重 |
|---|---|
| 草 | 步数 0.7、站立小时 0.3 |
| 水 | 睡眠时长分 0.6、入睡时间规律分 0.4 |
| 暗影 | 深睡比例 0.6、夜间 HRV 0.4 |
| 火 | 活动能量 0.6、高强度训练分钟 0.4 |
| 战斗 | 力量训练分钟 1.0 |
| 飞行 | 有氧运动分钟 0.7、步行跑步距离 0.3 |
| 电 | 高心率区间分钟 0.7、间歇训练分钟 0.3 |
| 地面 | 最近 7 天有活动的天数 0.6、爬楼层数 0.4 |

**稀疏的运动指标用 7 天滚动总量：** 有氧、力量、高强度、间歇、高心率区间、距离这些不是每天都有，如果按"今天 vs 平时"算，休息日会被当成"比平时差"。所以这些指标用"包括今天在内最近 7 天的总量"对比"基线的每周总量"（基线 = 过去 28 天总量换算成每周）。

**成长值每天增加：** `成长值 += 10 + 10 × max(0, 各回响里最高的 s)`。只要戴着就有保底 10 点，做得比平时好最多翻倍。每天最多 20 点，再加单项数据封顶（如步数 6 万）防止刷数据。

**五项属性各自的成长：** 每天 `2 + 2 × max(0, 该属性来源回响里最高的那个)`。

## 生活方式倾向（用于进化分支和野怪）

回响是"跟自己比"，适合衡量努力；但进化形态代表"你是什么样的人"，要用绝对标准。每种属性的倾向是 0–1，看一段时间（进化看 21 天）的平均水平对照健康指南：

| 倾向 | 计算（每项封顶 1） | 参考标准 |
|---|---|---|
| 草 | 0.7 × 日均步数 / 8000 + 0.3 × 日均站立 / 12 小时 | 常用的每日步数目标 |
| 水 | 0.6 × 睡眠得分（5 小时及以下为 0，7 小时及以上为 1）+ 0.4 × 入睡时间规律的夜晚占比（离中位数 60 分钟内） | 成人每晚至少 7 小时 |
| 暗影 | 平均深睡比例 / 15% | 健康成人深睡约占 13–23% |
| 火 | 0.6 × 日均活动能量 / 500 千卡 + 0.4 × 每周高强度 / 75 分钟 | WHO：每周 75 分钟高强度 |
| 战斗 | 每周力量训练 / 60 分钟 | WHO：每周至少 2 天力量训练 |
| 飞行 | 0.7 × 每周有氧 / 150 分钟 + 0.3 × 每周距离 / 15 公里 | WHO：每周 150 分钟中等强度 |
| 电 | 每周高心率区间 / 75 分钟 | 同 WHO 高强度 |
| 地面 | 0.6 × 每周活跃天数 / 5 + 0.4 × 日均爬楼 / 10 层 | — |

- 只用戴了手表的日子算平均，没戴不拉低。
- 所有参考值都在 `packages/engine/src/config.ts` 里，可以用批量模拟再调。

## 五项战斗属性

| 属性 | 来自哪种回响 |
|---|---|
| 体力 | 草 |
| 恢复 | 水、暗影 |
| 攻击 | 火、战斗 |
| 速度 | 飞行、电 |
| 防御 | 地面 |

每项属性有自己的成长值，按对应回响分配。物种和属性决定基础值的分布（比如飞行系速度高、火系攻击高），健康数据决定在这个分布上长多少：

```
基础属性 = 物种基础值 × (1 + 0.5 × log2(1 + 成长值 / 300))
```

用对数是为了边际递减：养 3 个月的宠物比养 1 个月的强，但不会强 10 倍。

## 心情

只影响 AI 说话和动画，不影响战斗：
- 开心：昨晚睡够 + 今天有活动
- 犯困：睡眠分低
- 无聊：连续两天活动明显低于平时
- 生病（小概率、温和）：连续 3 天以上睡眠很差，需要"好好睡一觉"才好
